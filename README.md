# Orchestero Homebrew tap

Homebrew casks for [ShowTake](https://showtake.app), the Mac app that films polished demos of your iOS and Mac apps,
driven by your coding agent.

```sh
brew install --cask orchestero/tap/showtake        # stable
brew install --cask orchestero/tap/showtake@beta   # beta builds
```

ShowTake updates itself (Sparkle), so `brew upgrade` is only needed if you turn automatic updates off. The casks are
updated by the release pipeline; please report problems at
[orchestero/showtake-issues](https://github.com/orchestero/showtake-issues/issues).
